# 簿記2級 トレーニング

日商簿記2級の仕訳問題をスマホ・iPad（Apple Pencil対応）で練習するためのWebアプリです。アプリ本体は `index.html` の1ファイルで、ほかにホーム画面用アイコン（`icon-*.png`・`manifest.webmanifest`）とオフライン用の `sw.js` があります。

## できること

- **サクッと5問**：苦手・未学習・復習のタイミングが来た問題を自動で選んで出題
- **○×スピード**：表示された仕訳が正しいかを1タップで答える10問タイムアタック
- **1問だけ**：30秒のスキマ時間用
- **オフライン対応**：一度開けば、インターネットがなくても使える（PDFの取り込みと動画を除く）。更新は、次にネットにつながった状態で開いたときに反映
- **iPad横向きは2列表示**：ホーム・本試験形式・成績の各画面
- **⏱ 模擬試験（90分・100点）**：第1問（仕訳5問）〜第5問を本試験と同じ配点で出題し、70点以上で合格ライン判定。第1問・第4問(1)の仕訳はCBTと同じく勘定科目を選択・金額を入力。途中でアプリを閉じても続きから再開できる
- **🎯 予想得点**：仕訳と本試験形式の最新の結果から「いま受けたら何点か」を大問ごとに表示し、いちばん伸ばせる大問を案内（成績タブ・ホーム）
- **🧮 電卓**：計算メモの「電卓」タブ。本試験の電卓と同じく左から順に計算・％・メモリー（M＋/M−/MR）。結果を「→ 解答欄へ」で入力欄に入れられる。iPadのキーボードでも操作可
- **📝 本試験形式（第2〜5問）**：本試験と同じ形式のオリジナル問題18題（工業簿記10題・商業簿記8題）。iPad＋Apple Pencil で
  - 問題用紙の**余白や資料に直接**計算を書き込める（ボックス図・タイムテーブル・T字勘定など）
  - **解答欄に直接**答えを書く →「採点する」で正解が解答欄の下に表示 → ○×をつけて点数を記録
  - 「⌨️ 入力」に切り替えると数字を入力して自動採点（有利・不利、借方・貸方はタップで選択）
  - 目安時間つきのタイマー、問題ごとのベストスコア、計算の流れがわかる解説つき
- **📷 教科書・過去問の写真に書き込む**：手持ちの教科書・問題集・過去問の **問題・解答用紙・解答** の写真（PDFも可）を **1問ずつセット** で取り込んで解ける
  - 取り込みは「種類ごとに選ぶ」がおすすめ：問題・解答用紙・解答をそれぞれまとめて選ぶ（何問ぶんでも一度に。PDFも可）と、1枚ずつ1問に自動で分ける。確認画面で、2ページ以上ある問題は写真をタップして「続き」にまとめられる。写真が「問題→解答用紙→解答」の順に並んでいる場合は「順番に並んだ写真」で3枚（または2枚）ずつ1問に分ける
  - 解答用紙に Apple Pencil で書き込み、問題は横のパネル（「📄 問題」タブ。書き込み・🔍拡大可）に表示。縦向きなら画面の下半分
  - 「📖 解答」でその問題の解答だけを表示。次の問題に進むと解答は自動で隠れる
  - 1問ごとに ○／△／× を記録。「×△だけ」で解き直したい問題だけを順に表示。◀ ▶ や一覧から問題を移動
  - **ほかの端末に送る**：一覧の 📤 で問題セットを1つのファイル（`.boki2`）にして、AirDrop などで送れる（例：iPhone で撮影・取り込み → iPad で解く）。受け取った側は「📥 共有ファイルから取り込む」。写真・書き込み・○△×がまとめて移る
  - あとから「＋ この問題にページを追加」「＋ 次の問題を取り込む」で追加できる。書き込みと○△×は自動保存。データはその端末の中だけに保存（PDFの読み込みにはネット接続が必要）
- **✏️ 計算メモ**：出題中にいつでも開ける手書きの計算用紙。iPadを横向きにすると問題の横に並ぶ（左利き向けに左側にも出せる：メモの「⇆」ボタンか設定から）
- 手書きは筆圧対応・黒／赤／青ペン・消しゴム・元に戻す／やり直し。Apple Pencil を使うと手のひらの誤タッチを防ぐため指はスクロール専用に（「✋ 指で書く」で切り替え）
- 仕訳は勘定科目を**タップ**して入力（金額入力なしの「勘定科目だけモード」もあり）
- 回答後に「ポイント」「1行ずつの考え方」「解説」「ひっかけ・覚え方」と、ふくしままさゆきさんの講義動画へのリンクを表示
- ヒント機能、まちがえた問題だけの復習、3回連続正解で⭐マスター
- XPとレベル、16種類のバッジ、1日の目標リング、連続学習日数、週間グラフ
- 分野ごとの正答率・苦手分野の表示、試験日カウントダウン
- 学習記録はスマホのブラウザ内（localStorage）に保存。バックアップ／復元も可能

### 問題について

- 全169問（商業簿記124問・工業簿記45問）。日商簿記2級の出題範囲に沿って、このアプリのために作成したオリジナル問題です（市販の問題集や過去問の転載ではありません）
- 各問題は「借方合計＝貸方合計」「ひっかけ選択肢が正解と重複しない」などを自動テストで確認しています

## GitHub Pages で公開する手順

### 1. ファイルを `main` ブランチに入れる

アプリのファイルは作業用ブランチ `claude/cool-gates-8vdvn6` にあります。まず `main` に取り込みます。

1. https://github.com/yoshi866/boki2-app を開く
2. 上部に黄色い帯で「claude/cool-gates-8vdvn6 had recent pushes」と出ていれば **Compare & pull request** を押す
   （出ていない場合は **Pull requests** タブ → **New pull request** → `compare:` で `claude/cool-gates-8vdvn6` を選ぶ）
3. **Create pull request** を押す
4. 次の画面で **Merge pull request** → **Confirm merge** を押す

### 2. GitHub Pages をオンにする

1. リポジトリの **Settings**（歯車アイコン）を開く
2. 左メニューの **Pages** を開く
3. **Build and deployment** の **Source** で **Deploy from a branch** を選ぶ
4. **Branch** で `main`、フォルダは `/ (root)` を選んで **Save**
5. 1〜2分待ってページを再読み込みすると、上部に公開URLが表示されます

公開URL： **https://yoshi866.github.io/boki2-app/**

### 3. スマホのホーム画面に追加する（おすすめ）

- **iPhone（Safari）**：公開URLを開く → 共有ボタン（□に↑）→「ホーム画面に追加」
- **Android（Chrome）**：公開URLを開く → 右上の︙ →「ホーム画面に追加」

アプリのようにアイコンから起動できます。

## 学習記録についての注意

- 記録は**そのスマホのそのブラウザ**にだけ保存されます（別の端末・別のブラウザとは共有されません）。
- ブラウザの履歴・サイトデータを消去すると記録も消えます。
- iPhoneのSafariでは、長期間（7日程度）サイトを開かないと保存データが削除されることがあります。ホーム画面に追加して使うと消えにくくなります。
- 心配なときは「設定」→「学習記録のバックアップ」で文字列をコピーし、メモアプリなどに保存しておいてください。

## 問題を追加・修正したいとき

本試験形式の問題は `const EXAMS = [` の部分です。`sheet` の中の `[[キー]]` が解答欄、`ans` が正解です（`[[キー=有利|不利]]` で選択式）。


`index.html` の中の `const QS = [` から始まる部分が問題データです。次の形式で1問ずつ書かれています。

```js
{id:'s01', cat:'shohin', q:'問題文',
 d:[['借方の勘定科目', 金額]], c:[['貸方の勘定科目', 金額]], x:['ひっかけ選択肢', ...],
 e:'解説'},
```

- `id` は他と重ならない名前にしてください（記録はこのidで保存されます）
- `cat` は分野（`CATS` に一覧があります）
- GitHub上でファイルを開き、鉛筆アイコン（Edit）から直接編集して **Commit changes** すれば、数分後に公開ページにも反映されます
